Playstation 4

Button Usage
B (○) Button Select item in inventory
A (✕) Button
  1. Jump
  2. Back
X (◻︎) Button
  1. Toggle Inventory
  2. Exit UI screens
Y (△) Button
  1. Social Portal
  2. Equip/Unequip in Inventory
Right Stick Move Pointer
Start Button In-Game Menu
Shoulder Right 2 Button Punch/Wrench/Place
Shoulder Right 1 Button Browse Right in Inventory Hotbar
Shoulder Left 2 Button Toggle (Wrench/punch)
Shoulder Left 1 Button Browse Left in Inventory Hotbar
Select Button Events and Leaderboards
Left Stick
  1. Move
  2. Browse Menus
Pad Left Button Drop Items in (Inventory/Hotbar)
Pad Right Button Open/Close Chat and Log Window
Pad Up Button
  1. Zoom in
  2. Trash item in inventory
Pad Down Button
  1. Zoom out
  2. Item Information in Inventory
Pad Button Unused Button Sprite
