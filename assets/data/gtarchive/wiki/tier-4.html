Robots.txt

A robots.txt file is a text file that contains instructions for web robots (also known as web crawlers) on which pages of a website to crawl or not to crawl. It is a part of the Robots Exclusion Protocol (REP), which is a group of web standards that regulate how robots crawl the web, access and index content. The file is hosted on the web server and can be viewed by typing the full URL for the homepage and then adding /robots.txt The file is mostly intended for managing the activities of good bots like web crawlers, since bad bots aren’t likely to follow the instructions. A good bot, such as a web crawler or a news feed bot, will attempt to visit the robots.txt file first before viewing any other pages on a domain, and will follow the instructions. A bad bot will either ignore the robots.txt file or will process it in order to find the webpages that are forbidden.

A robots.txt file helps manage the activities of these web crawlers so that they don’t overtax the web server hosting the website, or index pages that aren’t meant for public view 1. It’s important to note that all subdomains need their own robots.txt file.
