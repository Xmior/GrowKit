Moderator Commands

Command Description
/ban This let's any moderator to ban anyone from the game for a specified time. It will also broadcast "** The Ancients have used Ban on <Name>! **" at the user's world, if they are online.

Usage is: /ban <partial name, exact match or userID> <minutes> <optional filters: (soft, hard, ip)> <optional reason>

/pban Works nearly identically to the /ban command. This would broadcast "The Ancient Ones have Banned <Name> ** (/rules to see the rules!)" to the whole server if the user is online.
/tape This let's a moderator Duct Tape a target person for X minutes. It will also broadcast they were taped to the world.

Usage is: /tape <partial name, exact match or userID> <minutes> <optional filters: (soft, hard, ip)> <optional reason>

/ptape This would broadcast they were taped to the whole server as long as the user is online.
/curse This would let a staff member curse a player to the world HELL for X minutes (meaning they can not leave until the Curse is over). It will also broadcast they were cursed to the world.

Usage is: /curse <partial name, exact match or userID> <minutes> <optional filters: (soft, hard, ip)> <optional reason>

/pcurse This would broadcast they were cursed to the whole server if the user is online.
/tapecurse Duct tapes and curses a player with one command!

Usage: /tapecurse <exact name, partial name, or UserID> <time> <optional: reason>

/silence This would let a staff member silence a player for X minutes. This means they can not say a word even if they sent a message. This will broadcast they were cursed to the whole world they are at.

Usage is: /silence <partial name, exact match or userID> <minutes> <optional filters: (soft, hard, ip)> <optional reason>

/psilence This would broadcast they were silenced
/sbban This will ban a person from being able to use the /broadcast (or /sb) feature for X minutes. It would also broadcast the Broadcast Ban to the world.

Usage is: /sbban <partial name, exact match or userID> <minutes> <optional filters: (soft, hard, ip)> <optional reason>

/psbban This would broadcast they were broadcast banned.
/boot This will let a mod ban a player from the world they are at, if they have access. Same as /ban for ordinary players.

Usage is: /boot <exact match or partial name>

/aban This command would simulate a fake autoban on an user. It ignores the <minutes> argument even though it let's you to write it, using this command instead will always ban the person for 30 days.

Usage is: /aban <partial name, exact match or userID> <minutes> <optional reason>

/note This will let a moderator leave notes about a player that only other staff members can see! If the <text message> argument is empty, it will note the user as "<the target's name>".

Usage is: /note <partial name, exact match or userID> <text message (it would add this as the note)>

/warn This will let a moderator do a warning on the user's screen if they are online.

Usage is: /warn <partial name, exact match or userID> <text message (it would warn for this)>

/notes This command will let a staff member view the notes of the target user (bans, notes, etc)

Usage is: /notes <partial name, exact match or userID>

/info Shows information about a player such as their IP address, account creation date and total worlds made ever.

Usage is: /info <partial name, exact match or userID>

/infoex Shows extra information about a player such as their World Locked worlds, Inventory items and level.

Usage is: /infoex <partial name, exact match or userID>

/punish Opens a dialog box that shows someone's latest few notes, alternate accounts (according to RID (Robinson ID)) and let's you ban for template durations.

Usage is: /punish <partial name, exact match or userID>

/remove Let's you remove any item from a player's inventory (if they have it).

Usage is: /remove <partial name, exact match or userID> <count of items to remove> <full item name or ID>

/reports Shows a list of reported worlds according to the amount of reports the world has.
/find Finds a player from the database according to the provided name. Gives you information such as their account flags and unique id.

Usage is: /find <exact match>

/warpto Let's you warp directly to a target player.

Usage is: /warpto <partial name, exact match or userID>

/playerreport Checks player reports.
/ipcheck Finds up to 40 users with the same IP address as the provided player name.

Usage is: /ipcheck <partial name, exact match or userID>

/maccheck Finds up to 40 users with the same MAC address as the provided player name.

Usage is: /maccheck <partial name, exact match or userID>

/devicecheck Finds up to 40 users with the same device ID as the provided player name. This command is only 90% accurate.

Usage is: /devicecheck <partial name, exact match or userID>

/ridcheck Finds up to 40 users with the same RID (Robinson ID) as the provided player name.

Usage is: /ridcheck <partial name, exact match or userID>

/vidcheck Finds up to 40 users with the same VID as the provided player name.

Usage is: /vidcheck <partial name, exact match or userID>

/aidcheck Finds up to 40 users with the same AID as the provided player name.

Usage is: /aidcheck <partial name, exact match or userID>

/sidcheck Finds up to 40 users with the same SID as the provided player name.

Usage is: /sidcheck <partial name, exact match or userID>

/ghost Toggles ghost mode. While a ghost, you can walk through walls. The antihack systems won't pick you up as a cheater because the server knows you are a mod.

You can also jump an unlimited number of times to sort of "fly". If you have a desktop client you can also go down. On phone client, you can use joystick.

/invis Toggles invisibility. While invisible, no one can see you and your jumps don't make a sound.
/nick Let's you change your name to anything between 3 and 20 characters. It also let's you to use dots (.) or dashes (-)

Usage is: /nick <new name>

/massworldban World bans everyone from the world for one hour. This does not require admin permissions in the world.
/masskick Kills everyone in the world. Very similar to /kickall, but it just does it instantly. Interestingly enough when you run this command, it will show Used fireball on X people in <world name> (Mass: )
/massfreeze Used to freeze everyone in the current world for X seconds. This is mostly used for fun!

Usage: /massfreeze <seconds> <optional: comment>

/massban Bans everyone in the world for X minutes. Maxium duration for it is 5 days.

Usage is: /massban <minutes> <comment>

/masstape Duct Tapes everyone in the current world for X minutes. Maxium duration for it is 5 days.

Usage is: /masstape <minutes> <comment>

/masscurse Curses everyone to the world HELL for X minutes. Maxium duration for it is 5 days.

Usage is: /masscurse <minutes> <comment>

/banworld Bans everyone in the world for one hour and closes it so only moderators (or above) can enter it.
/nuke Bans every admin and owner for X minutes. Also closes the world.

Usage is: /nuke <minutes> <note>

/pnuke Identical to /nuke, but just broadcasts the infamous "<World> was nuked from orbit. Play safe, everybody!" message for everyone to see

Usage is: /pnuke <minutes> <note>

/casinoban This works as a macro for "/nuke 1051200 casino | Perma-08" (it executes the command). Used in casino worlds.
/pcasinoban This works as a macro for "/pnuke 1051200 casino | Perma-08" (it executes the command). Used in casino worlds.
/rename Let's a mod change a player's display name to something else (they still log in with their old name). This will give the account the "NAMELOCK" flag meaning they can no longer create a GrowID. Only a game admin can revert this name change.

Usage is: /rename <user> <new name>

/renameworld Renames a world without costing you “Change of Address”

Usage: /renameworld <new world name>

/transferworld Transfer a world into a specific name or userID
/warptolock Warps you to the world lock of your current world.

clearobject: used to clear dropped items.

Telnet Commands

Command Description
/tail Used to toggle log contents on telnet. Used when an admin needs to do commands on the telnet.

Usage: /tail

/altcheck Checks for alternate accounts of an user. It is not known what form of alternate check it uses (such as RID, IP, device ID or etc.)

Usage is: /altcheck <partial name, exact match or userID>

/players Shows all the local players online in the current sub server.
/load Reloads the server configuration file.
/mods Shows the online moderators like in the game.
/set Sets a player bit flag (such as MOD or SMOD). These flags change the permissions or rules of the target account.

Usage is: /set <userID> <setting>

/unset Removes a player bit (such as MOD or SMOD)

Usage is: /unset <userID> <setting>

/rankedworlds Shows the currently highest ranked worlds.
/shutdown Kills game server
